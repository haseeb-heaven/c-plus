# ISO C17 Library Coverage Audit (`libc/` & `stdlib/safe/`)

Complete honest classification of all **25 ISO C17 headers** on branch `agent/modern-stdlib`.

Classifications:
- `IMPLEMENTED`: implemented directly in C+ (`libc/src/`, `stdlib/safe/src/`) with tests.
- `VENDORED`: backed by pinned upstream permissive-licensed library (`rurban/safeclib` MIT, `musl` MIT, `yyjson` MIT, `exceptions4c` Apache-2.0).
- `HOST-DELEGATED`: thin NULL/bounds-hardened logged adapter over the host C toolchain (`cplus_*` in `libcplus_hardened_libc.a/.dylib|.so` and `cplus_*_s` in `libcplus_safecrt.a`).
- `PARTIAL`: subset of header functions available; remaining routines noted explicitly.
- `UNSUPPORTED`: not shipped in `libc/` or `stdlib/safe/`; exact blocker documented.

## Gap-closing update (this branch)

A further **202 ISO C17 APIs** were added as `PLATFORM_BACKED` namespaced wrappers
across `<fenv.h>`, `<time.h>`, `<wchar.h>`, `<wctype.h>`, `<complex.h>`, `<math.h>`
(float + long double), `<stdlib.h>` and `<inttypes.h>`. Every one has a source
file, a test file, an exact host backend, a contract and a documented safety
limitation in [`API_TEST_MATRIX.md`](API_TEST_MATRIX.md) and
`libc/contracts/c17_contracts.json`. All are host delegations — none is counted
as a bundled or upstream implementation. Logging and telemetry evidence is in
`tests/libc/test_logging_telemetry.c`.

Still `UNSUPPORTED` after this slice: Annex K `bsearch_s`/`qsort_s`,
`asctime_s`/`ctime_s`, `strerrorlen_s`, `tmpnam`/`gets_s`, and standalone C11
`<stdatomic.h>` / `<tgmath.h>` ABI symbols (type-generic compiler constructs
cannot be represented as single C linker symbols). The complete FILE buffering
engine is intentionally not reimplemented; file I/O delegates to the host `FILE*`.
