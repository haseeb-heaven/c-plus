## Evidence rules

- **NO EVIDENCE** means no dedicated test/contract/source file was found for that symbol; a token mention in a shared corpus is *not* treated as a passing test.
- **TESTED** means a dedicated test file exists and names the symbol. It does **not** imply Rust-equivalence or that every UB path is guarded.
- **COMPILER-ENFORCED** (compile-time format attributes / header macros) is kept strictly separate from **RUNTIME-ENFORCED** (checked library calls at run time). Neither implies the other.
- **PLATFORM_BACKED** is host-CRT delegation; **BUNDLED** is implemented in `libc/src` / `stdlib/safe/src`; **UPSTREAM** is vendored safeclib/musl code; **PARTIAL** means a header-only macro/alias with no standalone C ABI symbol; **MISSING** means no implementation or host backend was found. **PLATFORM_BACKED** rows make no bundled-implementation claim.
