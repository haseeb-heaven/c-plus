## Headline risks (ordered by severity)

1. **The authoritative generated evidence report is red.** `docs/FINAL_EVIDENCE.md` (untracked, generated by `tools/run_final_evidence.sh`) records `Overall result: **FAIL**`, `PASS=15 FAIL=1 TIMEOUT=0 BLOCKED=0 (total 16 suites)`. The failing suite is `libc-tests`: `libc tests: 86 passed, 4 failed` (see `build/final-evidence/logs/libc-tests.log`). The 4 failures are the 4 newly added libc tests whose implementation sources were not in the build at that time: `test_c23_remainders.c` (compile errors: `timespec_get` / `TIME_UTC` undeclared under `-std=c99`), `test_cplus_atomic.c`, `test_math_c23_farith.c`, `test_math_c23_hypot3_f16.c` (linker `Undefined symbols for architecture arm64`). This must be fixed and the report regenerated before any release claim. Note: that run (started `2026-11-23T01:17:21Z`) predates the currently uncommitted build-wiring edits.
2. **New C sources added but not wired into the build.** At final snapshot, 3 of 5 new implementation files are still absent from both `libc/CMakeLists.txt` and `tests/libc/build_libc.sh`: `libc/src/c23/remainders.c`, `libc/src/math/math_c23_farith.c`, `libc/src/math/math_c23_hypot3_f16.c`. Documentation states these were deliberately left unwired under "strict ownership" and need an orchestrator/toolchain decision (`docs/libc/C23_FARITH_CLOSURE.md:334-344`, `docs/libc/API_GAP_CLOSURE_PLAN.md:187`, `docs/libc/IMPLEMENTATION_PLAN.md:305`). Wiring is actively in flux: `atomic_wrappers.c` and `math_c23_next.c` were added to both build files during this audit.
3. **2,417 untracked generated report artifacts, including compiled binaries and `.dSYM` bundles.** `tests/stdlib/reports/` contains 2,417 untracked files: 471 `*.log`, 468 `*.stdout`, 468 `*.stderr`, 1 `adversarial.json`, 1 `adversarial.txt`, plus 540 files under 180 `.dSYM/` bundles (180 `Info.plist` + 180 extensionless DWARF binaries + 180 relocations `*.yml`), plus 468 extensionless compiled executables under `logs/{default,strict-none,ubsan}/`. These are machine-local build outputs, not source. Do not commit them wholesale.
4. **56 tracked Mach-O arm64 executables are modified.** Every file under `tests/stdlib/agent2/results/run/` is a tracked, committed binary; all 56 are rewritten on each regeneration. `summary.json`/`summary.txt` changed only in `generated_at` and `head` (`1df837f` -> `ed2ac0f`). This is an established pattern (commits `e1ce162`, `b2afe4e`), but it bloats history and ties evidence to one host/arch. Group separately from source fixes so it can be dropped or regenerated on CI.
5. **One added runner is not part of the authoritative evidence set.** `tests/stdlib/run_adversarial.sh`/`.py` exists and discovers `tests/stdlib/regressions/*.cp`, but neither `tools/run_final_evidence.sh` nor `.github/workflows/` references it. The 10 `.cp` regression harnesses therefore are not executed by the final aggregator. Conversely, the f100 C/C+ harnesses ARE discovered by `tests/fuzz100/run.py` (`SEARCH_DIRS = tests/crt/fuzz, tests/stdlib/fuzz`; `.c` and `.cp` supported) and that runner IS invoked by the `fuzz100` suite.
6. **91 commits ahead of the remote / PR gate not run.** `docs/libc/REMOTE_GATE_EVIDENCE.md` lists remote checks as `UNVERIFIED` with placeholders (`<<PR17_HEAD_SHA>>`); gate condition is three green jobs on the PR head SHA. A local green run is not proof of the remote gate.
