# Consolidated dependency provenance

**Date:** 2026-11-23  
**Branch:** `agent/modern-stdlib`  
**Scope:** every third-party implementation that is vendored in this tree or whose source was copied into a C+ file. Documentation-only studies, system-linked libraries, rejected candidates and toolchain-dependent ideas are recorded separately below so they are not mistaken for vendored code.

## 0. Method and limits of this document

- The dependency set was verified by listing `third_party/` (9 directories: `clog`, `ctl`, `exceptions4c`, `intel-safestringlib`, `miniaudio`, `nuklear`, `safeclib`, `stb`, `yyjson`) and then searching outside it for copied upstream bodies (`libc/upstream/musl/`, `libc/src/c23_upstream_small.c`, `libc/src/math/math_c23_musl.c`, `runtime/include/cplus/clog.h`). These are **11 vendored/integrated dependencies**: the 9 `third_party/` entries plus LLVM libc and musl-derived code, whose integrated bodies live outside `third_party/`. (clog is counted among the 9; its code lives in `runtime/include/` with only its LICENSE under `third_party/`.)
- Exact pins are quoted only where a local file records them (`UPSTREAM_COMMIT`, `PROVENANCE.md`, on-disk header version macros, or a repository document with an explicit SHA). Where no local source determines a version or commit, this document says **undetermined** rather than guessing.
- **License identifiers below are transcribed from the on-disk `LICENSE` / `COPYING` / `NOTICE` files and from the local documents that quote them. This document performs no legal review and makes no claim of license compliance beyond what those local files state.** Dual-licensed libraries are reported with the alternatives the local file actually offers.
- "Compiled" means: the vendored source is named in a build script or CMake target on this branch. A header-only dependency included by consumers is recorded as "header-only (not archived)".
- Source documents used: `docs/stdlib/upstream-reuse.md`, `docs/stdlib/upstream_study/*.md` (7 files), `docs/UPSTREAM_AUDIT.md`, `docs/libc/C23_MATH_DEPENDENCY_CLOSURE.md`, `docs/libc/SAFECRT_INTEGRATION_PLAN.md`, `docs/UPSTREAM_LICENSES.md`, `docs/libc/DEPENDENCIES.md`, `docs/libc/C23_SMALL_UPSTREAM.md`, `docs/MODERN_STDLIB.md`, `docs/LOGGING.md`, `docs/SAFE_CRT.md`, all on-disk `LICENSE`/`COPYING`/`NOTICE`/`PROVENANCE.md`/`UPSTREAM_COMMIT` files, `scripts/build_safecrt.sh`, `tests/stdlib/run_stdlib_tests.sh` and the root `CMakeLists.txt`.

## 2. Unmodified upstream code vs. C+ modifications

### Unmodified upstream code currently present

- **safeclib**: full `src/`/`include/` trees are preserved; the local build compiles a selected subset. `src/extmem/timingsafe_bcmp.c` and `timingsafe_memcmp.c` are compiled **verbatim**, with only a `-Dinvoke_safe_mem_constraint_handler=...` build flag; the original `_timingsafe_*_chk` symbols are deliberately not prefixed (`PROVENANCE.md`).
- **Intel SafeStringLib**: upstream `include/`, `safeclib/` and `unittests/` files are preserved as vendored reference; two local integration edits are listed below.
- **yyjson**: `yyjson.c` / `yyjson.h` unchanged.
- **stb**: `stb_image.h` (v2.34) and `stb_image_write.h` (v1.19) unchanged.
- **miniaudio**: `miniaudio.h` (v0.11.26) unchanged.
- **Nuklear**: `nuklear.h` (v4.13.4) and `nuklear_sdl3_renderer.h` unchanged.
- **exceptions4c**: `exceptions4c.c` / `.h` unchanged.
- **musl reference tree**: files under `libc/upstream/musl/src/` and `include/` are preserved reference copies.
- **ctl**: all headers other than `ctl/vector.h` and `ctl/string.h` unchanged.
- **LLVM header/license text**: the SPDX/license header is reproduced verbatim in `libc/src/c23_upstream_small.c`.
