## Method

- Public names extracted with a regex pass over comment-stripped headers: EXTERN declarations plus function-like #define macros; constant/helper macros removed.
- Implementation sources mapped by clang -ast-dump=json FunctionDecl definitions (functions with a CompoundStmt body) plus nm -g symbols from per-file compile probes with the exact build-script CFLAGS/prefixes; call sites are not treated as implementations.
- Dependency closure computed transitively from nm undefined symbols resolved against the vendored source tree; headers safeclib_private.h/safe_config.h/safe_types.h are implicit for every source.
- Compile probe: clang (/usr/bin/clang, Apple SDK) -O1 -std=c99 with build/safe/config.h and build-script -D prefixes; 149 sources OK, 57 failed (see per-API source_compile_probe).

- **UNAVAILABLE** — no definition exists anywhere in `third_party/safeclib/src` for a header-declared name (count is 0 here: every header name has either a source or a header macro alias).

## Warnings

1. The C+ build uses a hand-written `build/safe/config.h` that defines `HAVE_C99` but not `SAFECLIB_HAVE_C99`; upstream sources that branch on the latter compile a different spelling than the public header declares (e.g. `_snprintf_s_chk` vs `snprintf_s`).
2. Vendored `include/safe_types.h` is a trimmed copy without the `char8_t` fallback present in `safe_types.h.in`; all `extu8/*.c` fail with `unknown type name 'char8_t'` under `-std=c99`.
3. `extstr/strlcpy.c` and `extstr/strlcat.c` fail on Darwin because the SDK `<secure/_string.h>` fortify macros redefine those names before the function definitions.
4. `wchar/wmemcpy_s.c` and `wchar/wmemmove_s.c` contain `#error sizeof(wchar_t)?` because `SIZEOF_WCHAR_T` is not defined by the C+ config header.
5. `cplus_sc_*` wrappers pass `BOS_UNKNOWN`, so the compile-time object-size checks in the safeclib `_chk` path are effectively bypassed for C+ callers; capacity checks in `stdlib/safe` adapters are separate.
6. `strtok_s` and `strnlen_s` carry local fixes recorded in `PROVENANCE.md` (2026-11-22); do not assume byte-for-byte upstream behavior for those two.
7. All build/link facts above come from the host compile probe and the checked-in build script only; no Windows or live-game build was performed.
