# ISO C17 Gap-Closing API / Test Matrix

This matrix documents the new UNSUPPORTED-gap-closing slice of the C+ hardened libc on branch `agent/modern-stdlib`.
Every function below is **PLATFORM_BACKED**: a namespaced `cplus_*` adapter that delegates to a named host C runtime
function, adding opt-in entry logging and lightweight checks while preserving host standard semantics. No function
in this slice is IMPLEMENTED_BUNDLED or IMPLEMENTED_UPSTREAM. Generated from the implemented source definitions;
the machine-readable companion is `libc/contracts/c17_contracts.json`.

## Classification legend

- **IMPLEMENTED_BUNDLED** — implemented directly in C+ with tests; not a host delegation.
- **IMPLEMENTED_UPSTREAM** — provided by a pinned permissive-licensed vendored upstream library.
- **PLATFORM_BACKED** — thin namespaced adapter delegating to a named host function (all rows below).
- **PARTIAL** — subset of the header surface available; remainder documented explicitly.
- **MISSING** — no implementation or host backend available.
- **UNSUPPORTED** — not shipped; blocker documented in `docs/libc/ISO_C_AUDIT.md`.

## Honesty note

A passing build, differential test or sanitizer run is evidence of behaviour on the tested host only. It is not a
proof of memory safety, nor a claim that raw C pointers become safe because a checked alternative exists.

Host backend availability was probed on Apple Clang 16 / macOS arm64; long-double complex/math symbols
were all present there. Platforms lacking them must gate the wrappers out, not reimplement them.
