Mapped-name checks: **16 passed, 0 failed**. Total failures including nm/TU-isolation probes: **0**.

Mechanism: the rewrite happens in the **including translation unit only**
(preprocessor `#undef`/`#define`). There is **no symbol interposition**:
a TU compiled without the header still relocates `malloc` to the host CRT,
and precompiled C libraries are unaffected. `-DCPLUS_SAFE_C_DISABLE`
suppresses every mapping and yields declarations only.

The hostile-input delta is a **safety** difference (refusal vs memory
corruption), not an ABI difference: no struct layout, calling convention,
or exported C symbol changes.
