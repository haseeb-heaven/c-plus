## Honest platform scope

macOS: every target was compiled AND executed with exact-output and exit-0
checks.  Windows: every target was compiled to a genuine PE32+ executable and
verified with `file`, but **Windows runtime execution is BLOCKED in this
environment** (Highball/Wine stalls on this host, as documented in
`tests/cross_platform_apps/RESULTS.md`), so Part B is NOT runtime proof.
Part C executed only the macOS binaries.  These results cover the listed
deterministic inputs and are not a general memory-safety proof.
