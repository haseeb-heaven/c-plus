# Upstream reuse: token-based lifetime/ownership borrow checker

Additive adaptation of SaferCPlusPlus's scope-pointer lifetime-token mechanism
into `stdlib/lifetime_adapt.hp` (C+ / C17). No fat pointers, no ABI or runtime
changes, no compiler edits.

## 2. The actual upstream lifetime/ownership mechanism

SaferCPlusPlus enforces lifetime safety primarily **statically**, by encoding a
lifetime token in the *type* of a pointer and requiring the target object to
carry the same token. The relevant exact source lines (commit above):

`msescope.h:98`
```cpp
class TScopeID {};
```
`msescope.h:140-141`
```cpp
typedef size_t lifetime_info1_t;
static const lifetime_info1_t no_lifetime_info1 = 0/*std::numeric_limits<lifetime_info1_t>::max()*/;
```
`msepointerbasics.h:1508-1516` — the token `_TID` parameter turns a raw pointer
wrapper into a *scope pointer* whose kind is part of its type:
```cpp
class TPointerID {};

/* TPointer is just a wrapper for native pointers that can act as a base class. */
template<typename _Ty, typename _TID = TPointerID>
class TPointer : public mse::us::impl::AsyncNotShareableAndNotPassableTagBase {
public:
    TPointer() : m_ptr(nullptr) {}
    TPointer(_Ty* ptr) : m_ptr(ptr) { note_value_assignment(); }
    TPointer(const TPointer<_Ty, _TID>& src) : m_ptr(src.m_ptr) { note_value_assignment(); }
```
`msepointerbasics.h:1524-1528` — dereference is guarded (checked before use):
```cpp
_Ty& operator*() const MSE_ATTR_FUNC_STR("mse::lifetime_no_elided") {
    assert_initialized();
#ifndef NDEBUG
    if (nullptr == m_ptr) {
        MSE_THROW(primitives_null_dereference_error("attempt to dereference null pointer - mse::TPointer"));
```
`msepointerbasics.h:876,900,912-913` — marker base classes carrying lifetime
*scope* information (an object targeted by a scope pointer must live to the end
of its scope; a scope pointer may not be stored in a longer-lived object):
```cpp

class ReferenceableByScopePointerTagBase {};
class ContainsNonOwningScopeReferenceTagBase {};
class XScopeContainsNonOwningScopeReferenceTagBase : public ContainsNonOwningScopeReferenceTagBase, public XScopeTagBase {};
```
`msescope.h:983-993` and `msescope.h:2985-2987` — the scope **owner** from which
borrows are obtained; it is non-copyable/non-movable and carries the marker bases:
```cpp
template<typename _Ty, lifetime_info1_t lt_info1 = no_lifetime_info1> class TXScopeOwnerPointer;
template <class X, lifetime_info1_t lt_info1, class... Args>
TXScopeOwnerPointer<X, lt_info1> make_xscope_owner(Args&&... args);
...
class TXScopeOwnerPointer : public mse::us::impl::XScopeTagBase, public mse::us::impl::StrongPointerAsyncNotShareableAndNotPassableTagBase
    , mse::us::impl::ReferenceableByScopePointerTagBase
    , mse::impl::first_or_placeholder_if_not_base_of_second<mse::us::impl::ContainsNonOwningScopeReferenceTagBase, _Ty, TXScopeOwnerPointer<_Ty> >
```

**Mechanism summary:** a `lifetime_info1_t` token (0 = "no lifetime") labels an
owner and the scope pointers into it; the `TScopeID` `_TID` tag distinguishes
scope pointers from ordinary pointers; marker bases restrict where such
pointers may be stored and ensure targets outlive their borrows; dereference is
guarded and throws on null/uninitialized. Ownership transfer / release
invalidates pre-existing scope pointers because they cannot escape the owner's
scope.

## 3. What was adapted, and how

C+ is C17: no templates, no inheritance, no non-type template parameters. The
type-level token therefore becomes a **runtime token stored with the borrow and
checked against the stdlib metadata table** — the same generation-token
machinery the repo already uses (`stdlib/error.hp:519-542` generation query and
check, `:564-585` transfer bumps the generation, `:354-368` release retires it
to 0; exposed as `stdlib_mem_token` / `stdlib_mem_check_token` in
`stdlib/memory.hp:86-119`).

| SaferCPlusPlus (static, type-level) | Adapted C+ form (`stdlib/lifetime_adapt.hp`) |
| --- | --- |
| `lifetime_info1_t`, `no_lifetime_info1 = 0` | `lifetime_token_t` (`unsigned long long`), `LIFETIME_NO_TOKEN = 0` — header lines 72-73 |
| `TXScopeOwnerPointer` / `make_xscope_owner` | `lifetime_owner` + `lifetime_owner_init` (lines 77-81, 118-146) |
| scope pointer (raw pointer tagged with `lt_info1`/`TScopeID`) | `lifetime_borrow` = `{ void *ptr; lifetime_token_t token; }` (lines 85-88) — a new additive descriptor, **not** a redefinition of `T*` |
| scope pointer cannot be stored beyond the owner's scope | documented discipline; enforced at access time by refusing stale tokens (borrows carry no static scope type in C17) |
| guarded `operator*`/`operator->` (`assert_initialized`, null throw) | `lifetime_check` (lines 95-113), `lifetime_read` (226-244), `lifetime_write` (248-266): token + range validated against metadata **before** any target byte is touched; failures are fail-closed (`STDLIB_FAIL` + `error`) |
| transfer/release invalidates old scope pointers | `lifetime_transfer` (177) bumps generation via `stdlib_transfer_ownership`; `lifetime_owner_release` (151) retires it via `stdlib_release`; both zero the source token |

Exact adapted source lines (key bodies):

```c
/* lines 95-113: metadata-only validation, no dereference */
static inline int lifetime_check(const void *ptr, lifetime_token_t token,
                                 error *err) {
    if (ptr == NULL || token == LIFETIME_NO_TOKEN) ... STDLIB_FAIL;
    if (stdlib_alloc_size(ptr) == 0) ... STDLIB_FAIL;
    if (!stdlib_alloc_check_generation(ptr, token)) ... STDLIB_FAIL; /* stale */
    return STDLIB_OK;
}
```
```c
/* lines 177-195: ownership transfer re-stamps the token; old borrows go stale */
static inline int lifetime_transfer(lifetime_owner *dst, lifetime_owner *src,
                                    error *err) {
    ...
    if (stdlib_transfer_ownership(&dst->ptr, &src->ptr) != 0) ... STDLIB_FAIL;
    dst->token = stdlib_alloc_generation(dst->ptr);
    src->token = LIFETIME_NO_TOKEN;
    return STDLIB_OK;
}
```
```c
/* lines 226-244: read validates token and range BEFORE copying any byte */
static inline int lifetime_read(const lifetime_borrow *b, size_t off,
                                void *dst, size_t n, error *err) {
    ...
    if (b == NULL || lifetime_check(b->ptr, b->token, err) != STDLIB_OK)
        return STDLIB_FAIL;
    cap = stdlib_alloc_size(b->ptr);
    if (off > cap || n > cap - off) ... STDLIB_FAIL;
    if (n != 0)
        __builtin_memcpy(dst, (const unsigned char *)b->ptr + off, n);
    return STDLIB_OK;
}
```

**No fat pointers / no ABI change:** ordinary `T *` values are untouched. The
two new structs are additive value descriptors. Only existing stdlib helpers
are called; no allocator, linker or compiler code was modified.

### UBSan environment note (pre-existing, not caused by this change)

A direct `--sanitize=undefined` build initially failed while compiling the
**external** `c-plus-core` runtime, before compiling this test:

```
c-plus-core/runtime/cplus_runtime.c:129:23: error: use of undeclared identifier 'CPLUS_EXIT_ARITHMETIC'
error: failed to compile instrumented C+ runtime
```

Reproduced with an untouched existing test
(`./build/c+ build --strict --sanitize=undefined tests/stdlib/memory_ownership/mo_alloc_edges.cp`)
— same error. Cause: the driver compiles that runtime with
`-I…/c-plus-stdlib/runtime/include`, whose `cplus/cplus.h` lacks
`CPLUS_EXIT_ARITHMETIC`, although `c-plus-core/runtime/include/cplus/cplus.h:85`
defines it (`= 110`). That file is outside this task's ownership, so it was not
edited. To obtain genuine UBSan coverage, `CPLUS_CLANG` was pointed at a
temporary wrapper (outside the repo) that adds `-DCPLUS_EXIT_ARITHMETIC=110`
to the clang invocation; the instrumented runtime and this test then built and
the UBSan run above passed cleanly. The workaround changes no source or ABI and
does not relax any check in this test.

## 5. Limits (documented, not bugs)

- C17 cannot reproduce SaferCPlusPlus's *static* scpptool enforcement. A borrow
  used outside `lifetime_read`/`lifetime_write` is not checked; callers must use
  the guarded accessors (runtime-check mode, not static mode).
- Single-threaded: the token is a scalar generation stamp, not a lock.
- Detection requires the owner to be a tracked `stdlib_alloc` block. A stale
  token is always refused because generations are monotonic, including when a
  later allocation reuses the same address (`la_reuse_stale_refused`).
- No aliasing/exclusivity rules and no static "borrow cannot escape scope"
  check; the token check happens at each guarded access, not at compile time.
