# 100 cross-platform apps — verification results

Generated by `generate.sh`: 100 deterministic plain-C apps, 10 app domains
(game engine, snake game, desktop, web, server, database, audio, video,
graphics, utility) × 10 variants. Each app validates hostile input and exits 0
only when the good value is intact and both hostile values are refused (-1).
The **same source** is built for macOS native and Windows PE.

## macOS (native, Apple clang 16)

```
MACOS_APPS built=100 pass=100 fail=0 build_fail=0
```

Command: `sh tests/cross_platform_apps/run_macos.sh`. Each app built with
`/usr/bin/clang -O2 -Wall -Wextra -pedantic` under a 60 s bound and run with a
20 s bound; exact stdout checked for `-1 -1`; stderr empty.

## Windows PE (cross-compile, mingw-w64 x86_64)

```
WINDOWS_BUILD compiled=100 verified_pe=100 fail=0
```

Command: `sh tests/cross_platform_apps/run_windows_build.sh`. Each app built
with `x86_64-w64-mingw32-gcc -O2` under a 60 s bound and verified with `file`
as `PE32+ executable (console) x86-64, for MS Windows`.

## Windows runtime (Highball / Wine on Apple Silicon) — BLOCKED

```
WINDOWS_RUNTIME BLOCKED reason=highball-wine-stall probe_rc=124 apps=100
```

Highball CLI 0.10.22 with engine `x64-crossover26.3-r27` is installed and two
bottle engines exist, but a trivial `hello.exe` did not complete within 300 s;
the underlying `wine` process entered uninterruptible sleep (state U). A
bounded 20 s probe reproduced the stall (`probe_rc=124`, timeout). Therefore
none of the 100 PE apps could be *executed* under Wine/Highball here. This is
reported as BLOCKED, **never** as a pass; no Windows runtime output claim is
made. `run_windows_runtime.sh` is ready: if Highball becomes usable it runs
all 100 with bounded timeouts and records exact outcomes.

## Honest scope
macOS execution is verified for all 100 apps; Windows binaries are built and
verified as genuine PE32+ executables but not executed because the local Wine
runtime stalls. This is evidence for these deterministic inputs, not a proof
of full memory safety or cross-platform correctness.
